# 86运行库

Windows 10 / 11 一键运行库合集。单个 exe、零依赖、免安装，双击即用：自动检测本机已装的各类运行库，勾选缺失项后一键下载安装；同时附带系统 DLL 体检与补齐修复。

## 功能

- **Microsoft Visual C++ 运行库**：VC++ 2005 ~ 2015-2026（v14）全系列 x86/x64，自动识别已装版本。
- **.NET 运行库**：.NET Framework 3.5（系统可选功能，含 Windows Update 环境自动修复与重试）、4.x 检测。
- **游戏 & 经典运行库**：XNA、Visual J#、VB 运行库等老程序依赖。
- **其他常用运行库**：Java、Silverlight 等常见组件检测与安装入口。
- **系统组件修复（DLL 补齐）**：116 类 × 双架构共 231 项常见缺失 DLL（含 92 个 DirectX DLL）体检；优先从本机 WinSxS 复制（带 PE 架构校验），本机没有的自动下载官方运行库以 `/repair` 模式补齐。
- 下载 + 本地缓存：安装包首次联网下载到 exe 同级 `packages/` 目录，之后可在其他机器离线复用。
- 分页勾选界面：每页实时显示"已选 x/y"，支持全选/反选/仅选未安装/仅选推荐/作用于所有页；安装期间可取消。

## 使用

1. 下载 Releases 中的 `86运行库.exe`（或自行编译，见下）。
2. 双击运行——**界面以普通权限启动，不会弹 UAC**。
3. 等待自动检测完成，勾选需要的运行库，点击"开始安装选中的运行库"。
4. 此时才会弹出一次 UAC 授权（安装动作由另起的提权工作进程执行，见"权限设计"）。

## 编译

无需安装任何 SDK：使用 Windows 自带的 .NET Framework C# 编译器（`csc.exe`）。

```
双击 build.cmd
```

产物为 `86运行库.exe`（产品名从 `src/appname.txt` 读取，`build.cmd` 保持纯 ASCII 以避免代码页乱码问题）。

要求：Windows 10 / 11，系统自带 .NET Framework 4.x（默认都有）。

## 权限设计

主程序清单为 `asInvoker`：界面永远运行在普通完整性级别。这样任何由低完整性来源（远程桌面、虚拟机控制台、输入注入类工具）送来的鼠标键盘输入都不会被 Windows UIPI 静默丢弃——这正是很多"提权窗口按钮点了没反应"问题的根源。

真正需要管理员权限的安装动作，由界面在点击"开始安装"时通过 `runas` 拉起一个**无界面的 `--worker` 子进程**执行；日志、进度、取消、结果通过临时状态文件回传给界面展示。若进程本身已具备管理员权限（如从管理员命令行启动），则直接在当前进程内安装。

## 目录结构

```
src/RunTimePack.cs   全部源码（单文件 WinForms 程序）
src/app.manifest     应用清单（asInvoker + DPI 感知）
src/app.ico          程序图标
src/appname.txt      产品名（UTF-8）
build.cmd            一键编译脚本（纯 ASCII）
```
